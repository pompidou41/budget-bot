# Новая структура Google Sheets (v2)

Справочный документ: точное описание таблицы «Расходы/доходы», которую Claude пересобрал
10.09.2026 в отдельной сессии (не в этом репозитории). Здесь только факты о структуре
таблицы — какая она сейчас, что в ней редактируется, что считается формулами. Решения
по архитектуре бота (хостинг, креды, модель данных бота, UX) в эту сессию не входили и
здесь не описаны — это на усмотрение следующей сессии.

**Таблица:** `Расходы/доходы`
**URL:** https://docs.google.com/spreadsheets/d/1Yv9SQKDaDEpiTyyJ6LuiSnLVw1CcJEp_zLpnwBfIshE/edit
**Основная валюта:** USD. Суммы вводятся в валюте счёта, в USD пересчитываются формулами.

## 1. Листы таблицы и их роль

| Лист | Роль | Можно ли писать боту |
| --- | --- | --- |
| **Операции** | Единственное место ввода движений денег. Одна строка = одно событие (доход / расход / перевод). | Да — только столбцы A:L |
| **Счета** | Справочник счетов/карт/вкладов/кредитов. Остатки — формулы от «Операции». | Нет (кроме, возможно, разового добавления нового счёта — строка A:L, но J:K не трогать) |
| **Курсы** | Курсы валют к USD (авто через GOOGLEFINANCE + ручной override) и история курса USD/RUB по дням. | Нет, кроме ручного курса в D при необходимости |
| **Categories** | Справочник категорий/подкатегорий. | Нет (можно только добавлять новые строки в конец, если нужна новая категория) |
| **Дашборд** | Капитал по группам счетов, графики, сводка за 12 месяцев. Полностью формулы. | Нет |
| **Категории по месяцам** | Среднее/медиана/перцентили по категориям и по месяцам, с разделением на регулярные и разовые траты. Полностью формулы. | Нет |
| **Инструкция** | Текстовое описание для человека, как вести учёт. | Нет |
| **Подписки** | Ручной список регулярных подписок и их стоимости (сумма подтягивается в Дашборд). | Не относится к операциям, отдельный список |
| **копия Сводки** | Архив прежнего способа ведения учёта (2025–2026), больше не используется для ввода. | Нет, только чтение при необходимости истории |
| **Отчеты** | Старые отчёты поверх «копия Сводки». Не трогать, ссылается на архивный лист. | Нет |

## 2. Лист «Операции» — основная точка записи

Шапка (строка 1), по столбцам:

| Кол. | Заголовок | Кто заполняет | Тип / формат |
| --- | --- | --- | --- |
| A | Дата | вводится | дата |
| B | Тип | вводится | один из: `Расход`, `Доход`, `Перевод` |
| C | Счёт | вводится | ID из листа «Счета» (столбец A) — счёт списания (для дохода — счёт зачисления) |
| D | Сумма | вводится | число > 0, в валюте счёта C |
| E | Счёт куда | вводится, **только для Перевод** | ID счёта-получателя из «Счета» |
| F | Получено | вводится, **опционально для Перевод** | сумма в валюте счёта E. Если пусто — считается, что пришла та же сумма D (годится только если валюты C и E совпадают; при разных валютах это поле обязательно) |
| G | Категория | вводится | значение из «Categories», столбец A |
| H | Подкатегория | вводится | значение из «Categories», столбец B (см. §4 — список не фильтруется по категории на уровне валидации листа) |
| I | Комментарий | вводится | произвольный текст, на что/зачем операция |
| J | Разовая | вводится | чекбокс. Отмечаются крупные нетипичные траты (курсы, техника, разовая поездка) — они не портят медиану/среднее по обычным категориям в «Категории по месяцам» |
| K | Курс (ручной) | вводится, опционально | если задано — используется вместо курса из листа «Курсы» на эту операцию. Формат — как валюта счёта C (для RUB: рублей за 1 USD, напр. 86.5) |
| L | Добавлено | бот | дата и время записи строки (`dd.mm.yyyy hh:mm`, часовой пояс `BOT_TIMEZONE`). «Дата» (A) — когда операция совершена, «Добавлено» — когда её внесли. У строк до 17.10.2026 здесь скопирована «Дата» (настоящего времени записи для них нет); строки, внесённые руками, бот не помечает |
| M | Валюта | формула | валюта счёта C (VLOOKUP в «Счета») |
| N | Курс | формула | K, если задан, иначе курс на дату A из «Курсы» (для RUB — по истории дневных курсов, для остальных валют — текущий действующий) |
| O | Сумма USD | формула | пересчёт D в USD по курсу N |
| P | Валюта получ. | формула | валюта счёта E (для переводов) |
| Q | Курс получ. | формула | аналогично N, но для валюты P |
| R | Получено USD | формула | пересчёт «Получено (расч.)» (T) в USD по курсу Q |
| S | Потеря на обмене USD | формула | `O − R`. Разница между USD-оценкой отправленного и полученного — показывает спред/комиссию обмена |
| T | Получено (расч.) | формула | F, если задано, иначе D (см. правило в F) |
| U | Месяц | формула | первое число месяца операции — по нему считаются все агрегаты |

**Важно:** столбцы M:U — формулы. Каждая — одна `ARRAYFORMULA` **в ячейке шапки** (строка 1) вида
`={"Валюта";ARRAYFORMULA(IF(C2:C="","",…))}`: заголовок и под ним значения для всех строк. В строках 2+ этих
колонок нет содержимого, только вывод массива, поэтому строки данных можно сортировать, вставлять и удалять как угодно —
формулы это не задевает. Диапазон M1:U защищён (warning-only protection): Sheets спрашивает «Heads up!» перед
правкой серых колонок и при каждой сортировке из меню фильтра (так делает любая защита внутри диапазона фильтра —
сортировке это не мешает, жмёшь OK; галочка гасит окно на 5 минут). Если всё же вписать значение в серую ячейку M:U,
массив этой колонки не сможет развернуться (`#REF!` в шапке) — достаточно удалить вписанное. Бот пишет только A:L.

До 17.10.2026 формулы стояли в строке 2 (первой строке данных), и сортировка уносила их вниз — таблица ломалась.
Миграция: `scripts/migrate-added-column.ts` (`yarn migrate-sheet`).

**Сортировка.** Фильтр шапки покрывает `A1:U`: сортировать можно из меню фильтра любой колонки, в том числе по
«Дате» (когда совершена) и по «Добавлено» (когда внесена). Остатки, «Дашборд» и «Категории по месяцам» считаются
`SUMIFS` по целым колонкам и от порядка строк не зависят.

**Архив.** Строки счёта `ARCHIVE` скрыты **фильтром** по колонке «Счёт» (а не скрытием строк вручную: скрытые
вручную строки привязаны к номерам, и после сортировки под ними оказывались бы другие операции). Показать архив —
в меню фильтра «Счёт» отметить `ARCHIVE`.

Данные о типах для колонки B: `Расход | Доход | Перевод`.
Данные о `Разовая` (J) — булево, чекбокс.

В листе 493 строки истории (импортированы из архива, счёт `ARCHIVE`, с 01.10.2025 по 25.08.2026), дальше — новые операции.

## 4. Лист «Categories» — категории и подкатегории

Столбцы A:T (сверено с живой таблицей 11.09.2026):

- **A** — Категория (повторяется по строкам для каждой подкатегории — плоский список пар).
- **B** — Подкатегория, парная к A в этой же строке.
- **C** — пустой столбец-разделитель.
- **D:S** — по одной колонке на каждую категорию верхнего уровня (заголовок = имя категории), в колонке вниз — допустимые подкатегории именно этой категории. Это более удобный источник для двухшагового выбора «категория → подкатегория» (сначала показать список заголовков, затем непустые значения в найденной колонке), чем плоская пара A/B. Бот читает `Categories!C1:AZ`, пропускает пустые столбцы в начале и останавливается на `CategoryList`, поэтому новая категория-столбец перед `CategoryList` подхватится сама.
- **T (CategoryList)** — полный список категорий верхнего уровня (тот же список, что заголовки D:S).

Категории верхнего уровня сейчас: `Income, Housing, Food, Transport, Health, Personal, Subscriptions, Entertainment, Travel, Education, Family, Liza, Finance, Investments, Transfer, Other`.

Примеры подкатегорий (полный список — в листе, может расти):

- Income: Salary, Bonus, Freelance, Investment returns, Refunds, Gifts received, Cashback, Interest, Other
- Housing: Rent, Utilities, Internet, Repairs, Furniture, Household supplies
- Food: Groceries, Restaurants, Cafes & coffee, Delivery
- Transport: Fuel, Public transit, Taxi & rideshare, Parking, Car maintenance, Car insurance, Car loan payment, Other
- Health: Doctor, Pharmacy, Gym & fitness, Other
- Personal: Clothing, Beauty & grooming, Shopping
- Subscriptions: Streaming, Cloud storage, News & media, Mobile plan, AI, VPN, Other
- Entertainment: Cinema, Concerts & events, Games, Books, Hobbies, Other
- Travel: Flights, Hotels, Transport (trip), Food (trip), Activities, Visa & docs
- Education: Courses, Books & materials, Tuition, Study loan payment, Other
- Family: Gifts, Pets, Support to family, Other
- Liza: Flowers, Gifts, Other
- Finance: Bank fees, Interest paid, Taxes, Currency exchange loss, Documents & fees, Loan given
- Investments: Stocks, Crypto buy, Savings deposit
- Transfer: Between accounts, Cash withdrawal, CC payment, Crypto, Savings, Exchange, Loan payment, Salary split
- Other: Charity, Misc, Unknown

Эти названия — на английском (унаследовано от прежней версии листа Categories, которую вёл сам пользователь). Значения в «Операции».G/H пишутся ровно как в этом справочнике.

## 5. Лист «Курсы»

Столбцы A:F (строки данных с 4-й):

| Кол. | Заголовок | Формат |
| --- | --- | --- |
| A | Валюта | тикер: `USD, RUB, USDT, EUR, BTC, ETH` |
| B | Формат | `за 1 USD` (сколько единиц валюты за доллар, напр. RUB) или `USD за 1` (цена единицы в долларах) |
| C | Авто (GOOGLEFINANCE) | формула, тянет текущий курс |
| D | Ручной | если заполнено — перекрывает C |
| E | Действующий | формула: D, если задано, иначе C — это и есть «текущий курс», на него ссылаются другие листы |
| F | Примечание | |

USDT считается по паритету 1:1 к USD (не через рынок).

Справа (столбцы H:I) — история дневных курсов USD/RUB с 01.01.2025 по сегодня (дата | курс), формулой `GOOGLEFINANCE(..., "DAILY")`. По ней в «Операции».N ищется курс на дату конкретной операции (приблизительный VLOOKUP по дате, для другой валюты, кроме RUB — берётся текущий действующий курс E, истории по остальным валютам сейчас нет).

Новая валюта = новая строка в этом листе (плюс проверить, что тикер используется в «Счета».E при необходимости).

## 6. Бизнес-правила, которые стоит знать

- **Перевод** — единственный способ показать движение денег между своими счетами, включая обмен валют и покупку/вывод USDT. Расход/Доход никогда не затрагивают два счёта.
- Если у перевода валюты счетов C и E различаются, поле F («Получено») обязательно нужно указывать — иначе расчёт «Потери на обмене» (S) будет считать по номиналу, а не по факту.
- «Разовая» (J) — управляет только статистикой в «Категории по месяцам» (средние/медианы), на остатки счетов и капитал не влияет.
- «Курс (ручной)» (K) — override курса именно этой операции (например, реальный курс банка на конкретный обмен), а не общий курс на дату.
- Начальные остатки счетов (Счета.H) — это снимок примерно на май 2026 года (взято из прежнего листа Accounts), не 100% актуальны на сегодня; дата снимка — в примечании ячейки H1 листа «Счета».

## 7. Контекст: что было раньше (для справки, коротко)

До этой сессии учёт вёлся в листе «копия Сводки» (по неделям/месяцам, формулами вида `=1500+3000` в ячейках), с отдельным листом «Сводка», из которого бот в этом репозитории (`budget-bot`) читал список категорий и куда писал агрегированные суммы (`src/sheets/brief-parser.ts`, `src/sheets/brief-updater.ts`). Модель транзакции бота была плоской: `Date | Type | Category | Amount | Comment`, без счетов, без валют, без переводов, без курсов, без крипты.

Лист «Сводка» в этом состоянии таблицы больше не существует (переименован/удалён при пересборке), «копия Сводки» оставлена как архив только для чтения. Новая модель («Операции» v2 выше) полнее: счета, валюты, переводы, курсы, разовые траты — то, чего в прежней модели бота не было вовсе.

Дальнейшие решения — держать ли бота мультиюзерным, как встраивать счета/переводы/курсы в UX бота, какой хостинг и креды использовать — вне рамок этого документа.
