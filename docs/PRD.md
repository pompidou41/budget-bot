# Budget Bot — Product Requirements Document

## 1. Обзор продукта

**Budget Bot** — Telegram-бот для ведения личного бюджета. Пользователь отправляет сообщение с тратой или доходом в чат, бот парсит его и записывает в Google Sheets. Бот предоставляет саммари, графики, AI-аналитику и систему лимитов.

**Текущий статус:** пет-проект для личного использования.
**Перспектива:** возможная коммерциализация в будущем, поэтому код должен соответствовать современным стандартам и быть готовым к масштабированию без избыточной архитектуры.

---

## 2. Цели и мотивация

| Цель | Описание |
|------|----------|
| Контроль бюджета | Быстрый и удобный учёт доходов/расходов прямо из Telegram |
| Аналитика | Понимание паттернов трат через саммари, графики и AI-отчёты |
| Лимиты | Автоматические уведомления при приближении к лимитам по категориям |
| Развитие навыков | Практика Node.js / TypeScript на реальном проекте |

---

## 3. Целевая аудитория

**MVP:** один пользователь (автор). Бот авторизует по Telegram user ID.

**В перспективе:** любой пользователь Telegram, который хочет вести личный бюджет без отдельных приложений.

---

## 4. Функциональные требования

### 4.1. Запись транзакций

**Описание:** пользователь отправляет текстовое сообщение, бот распознаёт категорию, сумму и комментарий, записывает строку в лист "Transactions" Google Sheets.

**Формат сообщения:**
```
Категория Сумма Комментарий
```

**Примеры:**
- `Продукты 1500 Пятёрочка` — расход
- `Такси 350` — расход без комментария
- `Зарплата 80000` — доход

**Поведение:**
- Бот парсит сообщение и показывает inline-кнопки подтверждения: сохранить / изменить категорию / отмена.
- После подтверждения — запись в Google Sheets с полями: `Date | Type | Category | Amount | Comment`.
- Тип (расход/доход) определяется автоматически на основе категории.

**Приоритет:** P0 (MVP)

### 4.2. Отмена последней транзакции

**Описание:** команда `/undo` удаляет последнюю записанную транзакцию из Google Sheets.

**Приоритет:** P0 (MVP)

### 4.3. Список категорий

**Описание:** команда `/categories` показывает доступные категории с разделением на расходы и доходы.

**Приоритет:** P0 (MVP)

### 4.4. Саммари за период

**Описание:** пользователь запрашивает сводку по тратам/доходам за выбранный период.

**Метрики в саммари:**
- Суммарные траты и доходы
- Среднее значение транзакции
- Медиана
- Разбивка по категориям

**Выбор периода через inline-кнопки:**
- Текущая неделя
- Текущий месяц
- Прошлый месяц
- Всё время

**Приоритет:** P0 (MVP)

### 4.5. Графики

**Описание:** визуализация данных о тратах в виде графиков, отправляемых как фото в чат.

**Типы графиков:**
- Line chart — динамика трат по категориям за период
- Pie chart — распределение расходов по категориям

**Выбор типа графика через inline-кнопки.**

**Приоритет:** P1

### 4.6. AI-отчёт за месяц

**Описание:** генерация аналитического отчёта с помощью AI-модели (бесплатный tier).

**Содержание отчёта:**
- Анализ паттернов трат
- Сравнение с предыдущим месяцем (если есть данные)
- Рекомендации по оптимизации бюджета

**Способы получения:**
- По запросу (команда или кнопка)
- Автоматически раз в месяц (cron)

**Приоритет:** P2

### 4.7. Лимиты по категориям

**Описание:** пользователь устанавливает лимит трат по категории. Бот уведомляет при достижении порогов.

**Команда:** `/limit Продукты 15000`

**Уведомления:**
- При 80% лимита — предупреждение
- При 100% лимита — уведомление о превышении

**Хранение:** лист "Settings" в Google Sheets.

**Приоритет:** P2

## 5. Нефункциональные требования

| Требование | Описание |
|------------|----------|
| Авторизация | Только разрешённые Telegram user ID могут использовать бота |
| Хранение данных | Google Sheets (без собственной БД) |
| Логирование | Structured logging (pino) |
| Валидация | Все входные данные и env-переменные валидируются (zod) |
| Код | TypeScript strict mode, ESLint + Prettier |
| Зависимости | Актуальные версии, предпочтительно open-source |

## 7. Структура данных в Google Sheets

### Лист "Transactions"

| Поле | Тип | Описание |
|------|-----|----------|
| Date | string (YYYY-MM-DD) | Дата транзакции |
| Type | string | "Расход" или "Доход" |
| Category | string | Категория из предустановленного списка |
| Amount | number | Сумма |
| Comment | string | Необязательный комментарий |

### Лист "Settings" (фаза 4)

Хранение лимитов по категориям.

### Лист 1 (существующий)

Сводная таблица по неделям/категориям. В перспективе — автоматическая синхронизация из "Transactions".

## 11. Ограничения и допущения

- Google Sheets используется как единственное хранилище данных (без собственной БД).
- Gemini API free tier ограничен 15 запросами в минуту — достаточно для личного использования.
- QuickChart.io — внешний сервис для генерации графиков, зависимость от его доступности.
- Бот рассчитан на одного пользователя (MVP), но архитектура не должна препятствовать расширению на нескольких пользователей.
