# Budget Bot — Product Requirements Document (v2)

## 1. Обзор продукта

**Budget Bot** — личный Telegram-бот для ввода финансовых операций в Google-таблицу «Расходы/доходы» (структура v2,
см. [`SHEET_V2.md`](SHEET_V2.md)). Владелец пишет, надиктовывает или фотографирует, что произошло; AI превращает это
в операции формата v2, бот показывает черновик и после подтверждения записывает строку в лист «Операции».

Аналитика (капитал, остатки, статистика по категориям) живёт в самой таблице — листы «Дашборд» и
«Категории по месяцам» считаются формулами. Бот отвечает за быстрый и безошибочный ввод.

**Статус:** пет-проект для личного использования, один пользователь.

---

## 2. Цели

| Цель              | Описание                                                                        |
| ----------------- | ------------------------------------------------------------------------------- |
| Быстрый ввод      | Операция за несколько секунд любым способом: текст, голос, фото                  |
| Без ошибок        | Всегда черновик перед записью; счёт не угадывается; проверка по справочникам     |
| Полная модель v2  | Счета, валюты, переводы и обмены, разовые траты, ручной курс                     |
| Надёжная запись   | Пишутся только `Операции!A:K`; формулы и остальные листы не трогаются            |

---

## 3. Пользователь

Один владелец (`OWNER_TELEGRAM_ID`). Апдейты от других пользователей и из групп игнорируются молча.

## 4. Функциональные требования

### 4.1. Свободный ввод текстом — P0

- Любое сообщение разбирается AI в одну или несколько операций (`кофе 300 и такси 500 с альфы` → две карточки).
- Понимает относительные даты («вчера», «в понедельник»), сокращения сумм («1.5к»), алиасы счетов.
- Если счёт не назван явно — поле пустое, бот просит выбрать кнопками. Счёт **никогда** не угадывается.
- Если сумма названа в валюте, отличной от валюты счёта, — предупреждение в черновике, сохранить нельзя до исправления.

### 4.2. Голосовые — P0

- Расшифровка через Groq Whisper (`language=ru`), не длиннее 2 минут.
- Расшифровка показывается в карточке, дальше — как текст.

### 4.3. Фото чека / скриншот — P1

- Фото или картинка-документ (до 10 МБ) + необязательная подпись → AI распознаёт операции.

### 4.4. Черновик и правка — P0

- Карточка: тип, дата, счёт(а), сумма(ы), категория › подкатегория, комментарий, «Разовая», курс, предупреждения.
- Кнопки: Сохранить, Отмена, Счёт, Куда (перевод), Категория → Подкатегория, Дата, Тип, Разовая, Комментарий
  (необязательный: добавить, изменить или убрать).
- Ответ (reply) на карточку текстом или голосом — правка через AI («это было вчера», «сумма 450»).
- Сохранение возможно только когда `validate` не находит проблем.

### 4.5. Пошаговый мастер `/add` — P1

- Кнопками и короткими ответами: дата → тип → счёт → [куда] → сумма → [получено] → [категория] → подкатегория → комментарий.
- Работает без AI.

### 4.6. Отмена — P0

- `/undo` — последняя запись бота с подтверждением; «↩️ Отменить» под каждой записью.
- Очищается только строка, записанная ботом, и только если её не меняли вручную.
- Отменённая операция возвращается черновиком — можно поправить и сохранить заново.

### 4.7. Остатки `/balance` — P1

- Остатки из листа «Счета» (J/K) по группам, в валюте счёта и ≈ USD, итог капитала по счетам «В капитале».

### 4.8. Служебное — P1

- `/refresh` — перечитать счета/категории и проверить шапку «Операций».
- При несовпадении шапки запись блокируется, владелец получает сообщение.

## 5. Нефункциональные требования

| Требование      | Описание                                                                     |
| --------------- | ---------------------------------------------------------------------------- |
| Хранение данных | Google Sheets (операции, справочники) + `data/journal.json` (журнал отмены)  |
| Приватность     | Доступ только владельцу; текст/картинки уходят в Gemini (Google) через OpenRouter |
| Логирование     | Structured logging (pino)                                                    |
| Валидация       | env и ответы AI валидируются zod; операции — `validate` по справочникам      |
| Код             | TypeScript strict, ESLint + Prettier, vitest                                 |
| Хостинг         | Aeza VPS, PM2, GitHub Actions                                                |

## 6. Интеграции

| Сервис            | Назначение                              | Доступ                    |
| ----------------- | --------------------------------------- | ------------------------- |
| Telegram Bot API  | Интерфейс бота                          | grammY, long polling      |

| OpenRouter        | Разбор текста и картинок в операции     | Gemini Flash, JSON schema |

## 8. Вне рамок v2

- Несколько пользователей, регистрация, SQLite — удалены вместе с v1.
- Отчёты и графики в боте — их роль выполняет «Дашборд» в таблице (идея — `FEAT-015` в бэклоге).
- Запись в листы, кроме «Операции», и изменение справочников из бота.
