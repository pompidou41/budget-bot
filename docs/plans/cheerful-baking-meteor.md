# Plan: Sync Transactions to "Сводка" Sheet on Confirm

## Context

Бот записывает транзакции только в лист "Операции". Пользователь хочет, чтобы каждая подтверждённая транзакция также отражалась в листе "Сводка" — бюджетной сводной таблице с категориями по строкам и месяцами/неделями по столбцам. Ячейки содержат формулы вида `=1500+3000`, где каждое слагаемое — одна операция за неделю.

**Не в этом PR:** /undo реверс "Сводки" — задокументировать как `FEAT-015` в `docs/BACKLOG.md`.

## Структура листа "Сводка"

- Столбец A: названия категорий
- Строка 2: месяцы (объединённые ячейки, значение только в первой ячейке объединения)
- Строка 3: периоды недели — "1-8", "9-16", "17-24", "25-31"
- Данные: пересечение строки категории × столбца месяца+недели
- Формулы: `=1500+3000` (USER_ENTERED формат)

## Алгоритм нахождения ячейки

1. **Строка категории**: читаем `Сводка!A:A`, ищем точное совпадение с `transaction.category`
2. **Столбец периода**:
   - Читаем `Сводка!2:3` (строки 2 и 3 целиком)
   - Строка 2: forward-fill пустых ячеек от последнего непустого значения (месяц)
   - Строка 3: периоды недель
   - Вычисляем нужный месяц (RU название из `transaction.date`)
   - Вычисляем период недели по дню: 1-8 → "1-8", 9-16 → "9-16", 17-24 → "17-24", 25+ → "25-31"
   - Ищем столбец где одновременно совпадают и месяц, и период
3. **Чтение формулы**: `valueRenderOption: 'FORMULA'` чтобы получить `=1500+3000`, а не число
4. **Обновление**:
   - Пусто → `=amount` (add) или skip (subtract)
   - Есть формула → `existingValue+amount` (add) или `existingValue-amount` (subtract)
5. **Запись**: `valueInputOption: 'USER_ENTERED'`

## Обработка ошибок (silent fail)

- Категория не найдена в "Сводка" → `logger.warn`, return
- Месяц/период не найден → `logger.warn`, return
- Любая ошибка при обновлении "Сводка" → `logger.warn`, НЕ падаем (основная запись в "Операции" уже прошла)

## Файлы

### НОВЫЙ: `src/sheets/brief-updater.ts`

```typescript
export async function updateBriefCell(
  sheets: sheets_v4.Sheets,
  spreadsheetId: string,
  transaction: Transaction,
  mode: 'add' | 'subtract',
): Promise<void>;
```

Внутри:

- `getWeekPeriod(day: number): string` — вычисляет "1-8" | "9-16" | "17-24" | "25-31"
- `getMonthName(date: string): string` — русское название месяца из YYYY-MM-DD
- `columnIndexToLetter(index: number): string` — 0→"A", 26→"AA" и т.д.

### ИЗМЕНИТЬ: `src/sheets/index.ts`

Добавить экспорт `updateBriefCell` из `./brief-updater.js`.

### ИЗМЕНИТЬ: `src/bot/handlers/transaction.ts`

В `confirm` обработчике, **после** успешного `appendTransaction`:

```typescript
// Non-blocking — не ломаем основной флоу при ошибке
try {
  await updateBriefCell(sheets, user.sheetId, transaction, 'add');
} catch (error) {
  logger.warn({ error }, 'Failed to update Сводка on add');
}
```

## Проверка

1. Отправить боту транзакцию → подтвердить → проверить ячейку в "Сводка" (категория × текущий месяц/неделя)
2. Отправить транзакцию с категорией которой нет в "Сводка" → бот должен ответить "Записано" без ошибки (silent skip)
3. Отправить транзакцию, если месяц не настроен в "Сводка" → silent skip
4. `yarn typecheck` — проверка типов
