# Budget Bot — Memory

## Правила документирования

Когда делаю изменения функций бота, бизнес-логики, инфраструктуры:

1. **CLAUDE.md** — главный источник истины. Обновляю вразумеется:
   - Раздел "Архитектура" — если меняется структура функций/модулей
   - Раздел "Ключевые паттерны" — если меняются интерфейсы (UserRecord, Transaction, BotContext)
   - Раздел "Статус разработки" — когда фича готова
   - Раздел "Состояние" — если меняется управление состоянием

2. **docs/INFRA.md** — для инфраструктуры (PM2, GitHub Actions, деплой)

3. **docs/PLAN.md, docs/BACKLOG.md** — для планирования будущих фаз

### Когда НЕ обновлять:
- Просто рефакторинг приватных функций
- Баг-фиксы в пределах контракта функции
- Добавление comments в код
