Когда делаю изменения задокументировать их (при необходимости) в:

1. **CLAUDE.md** — главный источник истины.
2. **docs/INFRA.md** — для инфраструктуры (PM2, GitHub Actions, деплой)
3. **docs/PLAN.md, docs/BACKLOG.md** — для планирования будущих фаз
4. **docs/ARCHITECTURE.md** - "Архитектура" — если меняется структура функций/модулей, "Ключевые паттерны" — если меняются интерфейсы (UserRecord, Transaction, BotContext)
